## Expected
A clean platform dependency install obeys committed locks and exact tool versions; changed locks
fail visibly; `just verify-ticket` fails for unknown and unimplemented tickets. No per-App
dependency infrastructure exists ahead of F05.

## Observed
1. `just verify-locks` (log: `docs/development/evidence/logs/F01-verify-locks-a6b1121.log`, exit 0):
   uv 0.12.17 == pin; pnpm 10.34.5 == pin; node 24.21.0 == pin; python 3.13.9 == `.python-version`;
   `uv lock --check` exit 0; `pnpm install --frozen-lockfile --offline --ignore-scripts` exit 0;
   negative control: a copy of uv.lock with one altered version fails `uv lock --check` (exit 2).
2. Clean install path exercised by `just bundle-core` (`tools/bundle_core.py`): installs the pinned
   interpreter with `uv python install 3.13.9 --install-dir .alpha-runtime/python`, creates
   `.alpha-runtime/venv`, runs `uv sync --frozen --no-dev --no-editable` and verifies the installed
   `alpha.main` equals the source. Manifest `.alpha-runtime/core-runtime.json` records python
   3.13.9 and the uv.lock digest e608b62c…10fc.
3. Dispatcher (log: `docs/development/evidence/logs/F01-verify-ticket-negative-a6b1121.log`):
   `just verify-ticket F99` → "unknown ticket 'F99'", exit 2; `just verify-ticket F02` →
   "no implemented verification recipe yet", exit 3. `just verify-ticket F01` runs check,
   test-core, test-ui, test-integration and verify-locks and then lists the native checks as
   pending rather than passed.
4. Repository contains no per-App dependency profile, registry or installer; `.alpha-runtime` is
   the single platform runtime (F05 introduces App profiles).

## Attempts
1. Initial attempt pinned Node 25 (machine default); Vite 8/Vitest 5 refuse it under
   engine-strict. Re-pinned to Node 24.21.0 (LTS), justfile prefers the Homebrew node@24 keg.
2. Bundled runtime went stale silently (uv rebuilds path packages only on pyproject changes);
   fixed with `tool.uv.cache-keys` on sources plus forced reinstall and an installed-vs-source
   check (commit f448485).

## Limitations
The runtime is a development bundle located by a compile-time path; signed relocatable packaging
is F22. Homebrew keg preference is machine-specific convenience; the pin itself is enforced.

# F01.C04 — Interruption visible after restart; window close vs explicit quit differ

- Check: F01.C04 (evidence kind: native)
- Code: commit `a6b1121443f1d3cbd3d6bca94f43fde404286eac`; same build and protocol as F01.C01
- Environment: macOS 26.6.2 (25G83) arm64 Apple Silicon; uv 0.12.17; CPython 3.13.9 (uv-managed); Node 24.21.0; pnpm 10.34.5; rustc 1.98.1; just 1.58.0; Tauri 2.11.6 debug .app bundle
- Reviewer: self-review (coding agent)

## Expected
Closing the window keeps runtime, tray and running work alive and the window can be reopened;
explicit quit (tray/app menu) terminates Core and every worker tree; a run interrupted by quit or
by a Core crash is shown as interrupted after restart and is not resumed automatically.

## Observed
- On commit a6b1121: a run interrupted by an earlier Core restart is shown after relaunch as
  INTERRUPTED "Reason: the runtime restarted while it was running; it did not resume
  automatically" (run_20bfbe97…64b4, terminal_reason core_restarted_worker_orphaned; the orphaned
  worker pgid 78223 was terminated by startup reconciliation, log line in core.stderr.log).
- On commit a6b1121, host loss: SIGTERM to the host with Core idle → Core exited on its own within
  2 s (parent-watch), no processes left.
- Window close (16:33, this build): run_1802113e…4789 RUNNING; close button → window hidden;
  host 79670, Core 79702, worker 80489, child 80490 all alive; run still \`running\`, lease
  present, Core listening on 127.0.0.1:49165; host log "window hidden; runtime keeps running".
  Reopen event → window back with the RUNNING card and "Runtime connected". Runtime never
  restarted (same Core pid and port).
- Explicit quit with a running worker (16:33, this build): tray menu "Open Alpha / Quit Alpha" →
  "Quit Alpha" while run_1802113e…4789 was running. Within 14 s: no host, Core, worker or
  \`sleep\` process remained. SQLite: run interrupted, terminal_reason runtime_quit, 10 events;
  run.interrupted payload {"reason": "runtime_quit", "termination": {"grace_seconds": 2.0,
  "pgid": 80489, "sigterm_sent": true, "sigkill_sent": false}}; lease rows 0. Core log:
  "exit requested (runtime_quit): interrupted runs ['run_1802113e…4789']".
- Relaunch (16:34): Core up 2 s after \`open -n\`; the shell shows that run as INTERRUPTED
  "Reason: Alpha was quit while it was running; it did not resume automatically"; no worker was
  started for it (no automatic catch-up).
- Distinct behaviours confirmed on one build: close keeps the whole tree and the work; quit stops
  the whole tree and records the interruption.

## Result
PASSED on commit a6b1121 (self-review).

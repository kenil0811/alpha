# F06.C03 — Reference components contain reusable behavior and no exemplar-domain platform shortcuts

- Check: F06.C03 (evidence kind: review)
- Code: commit d949198
- Reviewer: self-review (coding agent). A founder review is invited; the points below say what to look at.

## What was reviewed
`packages/ui-kit` (components, data hooks, tokens, styles, REFERENCE.md, reference sheet),
`packages/ui-bridge`, `tests/ui/compositions/{review,entry}`, `templates/app`, the neutral
`entries_app` fixture, `tools/ui_build`, `tools/build_ui_profile.py` and Core's view enforcement.

## Findings
1. **No exemplar-domain terms or rules.** A case-insensitive search for calorie, kcal, food, meal,
   nutrition, protein, portion, recipe, job, recruit, resume, salary, vacancy, employer and
   linkedin across all of the above found 0 matches. Example data is neutral ("Example entry",
   "Item", "first/second/third", "note/task/idea").
2. **Behaviour lives in reusable components, parameterised by props.** Nothing in the kit knows a
   collection, field or action name:
   - `QuickEntry` takes a `parse` function.
   - `RecordTable` takes column definitions.
   - `ReviewQueue` takes decisions and `onDecide`.
   - `TrendChart` takes day points.
   - Data hooks take view and action ids declared by the App.

   The compositions' App-specific parts are only the entries fixture's names and the
   "<amount> <title>" parse rule.
3. **Generic behaviours are in the kit, not repeated in compositions.**
   - Confirmation before bulk actions.
   - Keeping decisions and drafts after a failure.
   - Labelled estimates and corrections.
   - Missing days shown as gaps, not zeros.
   - Focus return from the drawer.
   - Sandbox-safe submission (`Form`).
   - Plain-language errors (`friendlyError`).
4. **No shortcut around platform authority.** The kit's only data path is the bridge. It has no
   `fetch`, no Core URL and no token. The generated CSP sets `connect-src 'none'` and
   `form-action 'none'`, and the frame sandbox denies forms, popups and navigation. Core enforces
   the declared views, and the bridge host rejects undeclared views and malformed queries.
5. **No generic CRUD-only bar or UI DSL.** The template and REFERENCE.md steer builders to choose
   the interaction first (quick entry, review, trend) and use tables only for comparing many
   items. Custom React remains allowed with kit tokens.

## Things a human reviewer might still question

  item 1.

## Expected
Every `/api` request without the host-issued bearer token, with a wrong token, with a malformed
scheme, with an unapproved `Origin`, or with a non-loopback `Host` is rejected. CORS preflights
are answered only for host-approved origins. Core refuses to start without credentials.

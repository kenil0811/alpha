## What the render check does

The screen was built and sealed into the candidate Version as `dist/ui/index.html`, with its own
hash-pinned content security policy. The render check loads it in a frame sandboxed to scripts
only, which gives it an opaque origin. The frame sits on a harness page running the real
`@alpha/ui-bridge` host from the UI build profile.

Every bridge request reaches Core over the validator's pipes. Core answers it from the
candidate's isolated preview, with real App runs on the real profile and the real store, and only
within the screen's declared views and actions. Playwright serves both virtual origins from disk,
so no network is involved. The run recorded `ui_blocked_requests` 0.

The plan's primary interaction is to type "Buy milk" into the field labelled "Note" and press
Enter. It must store `{title: "Buy milk"}` and show "Buy milk". The populated state's sample data
is a long note created through the App's own `add_note` action.

## Found while qualifying this check live (F07.C03) and fixed

- **Fields matched by role.** The first live repair run was rejected twice because the check took
  the section "Write a note" for the field labelled "Note". Fields are now found by control role.
  The regression test is `test_fields_are_found_by_their_own_label_not_by_lookalike_titles`.
- **Type-checked screens.** A generated screen without the table's required `caption` crashed on
  load. The trusted build now type-checks screens against the kit's types, so the build fails with
  the exact line. The regression test is `test_a_screen_that_breaks_the_kit_types_fails_the_build_with_the_line`.
  The type check also caught an unsound line in one of my own test fixtures, which I corrected.
- **Error checks that cannot apply are skipped.** The failed-read check is skipped for a screen
  that reads nothing, and the failed-save check for an interaction the plan does not require to
  save. The skipped check is not required. The regression test is
  `test_a_screen_that_reads_nothing_is_not_asked_to_show_a_failed_read`.

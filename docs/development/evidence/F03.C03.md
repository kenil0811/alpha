## Gaps and next profile decision (for F20)
1. Reads are unrestricted by default: only the explicit denyRead list is protected. The worker profile therefore has to enumerate every sensitive root (user home, app data directory, other Apps' scratch, browser profiles, Keychain-related paths) or run workers under a dedicated account. Decision: keep the candidate; F20 must build the deny list from the real data layout and probe it with hostile fixtures.
2. Child processes are allowed and inherit the sandbox. Acceptable for pure workers; F20 must confirm process/resource limits (quotas, fork bombs) which srt does not provide.
3. Network is closed by default and loopback is denied, so broker access for App/Task workers needs an explicit allowance (srt allowedDomains with a port, or a Unix socket) — a design input for F05/F13, recorded here.
4. sandbox-exec is deprecated by Apple but functional on macOS 26.6; the fallback if it disappears is the plan's local VM decision, not silent relaxation.
5. Socket path length: srt's Unix sockets must live under a short TMPDIR (macOS 104-byte limit); the platform will provide one.

## Limitations
Feasibility only: a cooperative payload, not adversarial probes (F20). Nonsensitive synthetic fixtures; no real personal data touched.

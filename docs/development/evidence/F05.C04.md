## Limitations
Functional proof only, as the check states; this is not F20 containment qualification. Read-only file modes and separate processes are shown; a hostile worker's attempts to bypass them through other permitted paths (links, renames, another worker's scratch) are F20. The base interpreter lives in the development runtime directory; F22 supplies the signed relocatable bundle. Profile deletion, leases and cleanup journals are F22.

# F03 — UI boundary and sandbox feasibility

Status: complete (all three checks passed; self-review). Depends on F01 (complete).

## What was built

- `packages/ui-bridge` (TypeScript, contract 0.2): protocol types and validator
  (`protocol.ts`), `BridgeHost` (trusted shell side: one transferred MessagePort per session,
  session_id label checked on every message, grant enforcement for actions and read views,
  operations observable only by the session that created them, expiry, throttling, revocation
  that closes the port, handler errors sanitized) and `BridgeClient` (generated-UI side: accepts
  the handshake only from the exact parent window with exactly one port; typed errors).
  10 tests over real MessagePorts in Node.
- Shell qualification surface ("Isolation fixture" button): two frames of arbitrary React
  (`apps/desktop/fixtures/generated-ui`, built into one self-contained HTML with a hashed-script
  CSP by `scripts/build-fixture.mjs`) with `sandbox="allow-scripts"` (opaque origin), session A
  granted `synthetic.echo`, session B granted nothing; Revoke and Reload controls; host event log.
  Shell handlers reach Core with the shell's credential; the frames never see it.
- Host: custom protocol `alpha-ui://<app-id>/` serving the fixture with its own strict CSP as a
  response header; shell CSP gains `frame-src alpha-ui:`.
- Sandbox candidate: `@anthropic-ai/sandbox-runtime` 0.0.77 pinned under
  `tests/qualification/sandbox`; `just qualify-sandbox` runs a probe payload under `srt` on the
  real macOS seatbelt with a synthetic world and writes a JSON report.

## Findings

1. `srcdoc` (and blob:) frames inherit the embedding document's CSP, so the shell's policy
   blocked the fixture's inline script: generated UI must be served from its own origin. The
   `alpha-ui://` protocol is the mechanism; F06/F07 serve sealed static assets through it, keyed
   by App identity.
2. Sandbox-runtime probes (real sandbox-exec): denies reads of the deny-listed home/data
   directories, writes outside scratch, symlink escape, child reads of the canary, public and
   loopback TCP, HTTPS via its proxy and listening sockets; allows scratch writes. Reads outside
   the deny list and child processes are allowed (documented defaults) → F20 gap list.
3. `srt` needs a short TMPDIR for its Unix sockets (macOS path limit) and a Node on PATH; the
   sandboxed command is passed as separate argv tokens.
4. Launching a freshly rebuilt unsigned debug bundle through `open` can take minutes before the
   host spawns Core (first-launch validation); launching the binary directly is immediate.
5. The handshake must be frame-initiated (`bridge.hello` after the client's listener exists);
   posting the port on the iframe load event races React's effect scheduling.
6. The fixture builder's freshness stamp must include the bridge package sources it bundles.

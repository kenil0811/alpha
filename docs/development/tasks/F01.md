# F01 — Desktop/Core/worker bootstrap

Status: in_progress (native checks being collected). Owner: coding agent (self-review).
Snapshot digest: `a7dc7105c70a9b7def5ab60df6c77eabfd618128136dfc5cf7eb521999a71ef1` (see

## Goal

Boot the minimal desktop → Core → worker path: trusted shell, authenticated loopback transport,
durable Run/event tables, one synthetic worker profile, window-close vs explicit-quit behavior,
process-tree cancellation and restart reconciliation. No model integration, no generated apps.

## What was built (commit `1597ea1`)

- Monorepo toolchain: uv 0.12.17 / CPython 3.13.9, pnpm 10.34.5 / Node 24.21.0, Rust 1.98.1,
  exact pins and committed `uv.lock` / `pnpm-lock.yaml`; `justfile` recipes and the
  `just verify-ticket` dispatcher (`tools/verify_ticket.py`).
- `packages/contracts`: `Run`, `RunEvent`, `AppOwner`/`TaskOwner` (closed discriminated union),
  `ExecutionSnapshot`, `RunState`/`RunOrigin` per Current Release Specification §6; JSON Schema
  export and TypeScript generation with drift checks.
- `services/core`: FastAPI on `127.0.0.1:<os-assigned>`; bearer session token (constant-time
  compare), loopback `Host` check, approved-`Origin` check; SQLite control store with `runs`,
  `run_events` (per-run monotonic `sequence`, global rowid cursor) and `worker_leases`;
  `RunCoordinator` (queued → running → succeeded/failed/cancelled/interrupted, timeout,
  cancellation with process-group SIGTERM→SIGKILL, startup reconciliation of orphaned leases,
  graceful shutdown on SIGTERM, host parent-watch); synthetic worker profile
  (`alpha.workers.synthetic`, launched with `python -I`, allowlisted env, private scratch, new
  session).
- `apps/desktop/src-tauri`: Tauri 2.11.6 host. Launches Core from `.alpha-runtime` (uv-managed
  CPython + non-editable install of Core/contracts, prepared by `just bundle-core`) with
  `env_clear()` plus an allowlist and a random 32-byte session token; reads one readiness line;
  exposes `core_session` / `runtime_info` typed commands; `CloseRequested` → hide window; tray
  menu Open/Quit; `RunEvent::Exit` → SIGTERM Core, wait 5 s, SIGKILL.
- `apps/desktop/src`: React shell with tokens (`styles/tokens.css`), request panel, run list with
  plain-language states/reasons, SSE live updates resuming from a durable cursor.

## Decisions

- Synthetic runs are modelled as Task-owner runs (`plan_ref = worker-profile:synthetic`) rather
  than inventing an extra owner variant; the contract's owner union stays closed.
- The coordinator waits on the worker *leader* rather than on stdout EOF, then terminates the
  whole process group. A descendant inheriting stdout can therefore never keep a finished run
  alive, and descendants never outlive the leader.
- Timeout intent (`worker.timeout`) is recorded before termination; terminal reason
  `timeout_exceeded`.
- Core watches its parent pid and shuts down gracefully if the host disappears, so a host crash
  (or a killed test runner) cannot leave Core and worker trees orphaned. Discovered after finding
  four orphaned test Cores from a pytest session cut short by a closed output pipe.
- Node 24.21.0 (LTS) is pinned instead of the machine's default Node 25 because Vite 8 / Vitest 5
  refuse Node 25 under `engine-strict`.
- "Bundled Python" in F01 means the platform-managed `.alpha-runtime` (never the user's Python
  and never PATH). Signed relocatable packaging is F22.
- App commands are allowed for the trusted `main` window by Tauri's default; F03 restricts
  generated-UI windows explicitly.

## Known limitations

- Runtime is a development bundle at `<repo>/.alpha-runtime` located via a compile-time path;
  not relocatable, not signed (F22).
- One Core process per app data directory is assumed; running the dev binary and the .app at the
  same time shares the data directory.
- Shell is a single request/result surface by design (no future navigation built).

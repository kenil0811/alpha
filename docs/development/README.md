# docs/development

Where the product is going and what has been done.

- `direction-2026-09-27.md` — the current direction, what changed, what is done and what is left.
  Start here.
- `decisions/` — dated implementation decisions with their reasons.
- `M1-review.md` — the external review of the first milestone and its repair list (history).

The ticket-and-evidence process that ran until 26 September 2026 (F-numbered tickets, hashed
evidence files, `task_state.json`) is retired and its files removed; the planning snapshot it
came from is kept in `docs/archive/alpha-r2`. Progress now means real requests going through the
assistant and coming out as usable modules.
